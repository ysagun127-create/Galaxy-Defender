# 🚀 Galaxy Defender

A fast-paced **2D space shooter** built with Python and Pygame as an MCA mini project. Fight alien invaders, dodge asteroids, collect power-ups, and beat the high score!

## ✨ Features
- 🚀 Smooth spaceship movement and shooting
- 👾 Alien enemies and drifting asteroids
- 💚 Power-ups and multiple lives
- 🌌 Scrolling starfield and level progression
- ⏸️ Menu, pause, and game-over states
- 📊 Score saving and analytics dashboard

## 🛠️ Tech Stack
- **Pygame** — Game graphics and controls
- **NumPy** — Movement calculations
- **Pandas** — Score management
- **Matplotlib** — Score analytics



## ▶️ How to Run


Enter your player name in the terminal to start playing.

## 🎮 Controls

| Key | Action |
|---|---|
| Arrow Keys / WASD | Move |
| Space | Shoot |
| P | Pause / Resume |
| Enter | Start game |
| A | View analytics |
| R | Play again |
| Esc | Back to menu / Quit |
